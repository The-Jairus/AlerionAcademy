Certificate details

Each course now chooses whether its certificate is signed or unsigned, and who signs it. The signer above is only the fallback for a signed course that left those fields blank.

Email

Every certificate issued is emailed to the employee with a copy to the administrator. Until this is configured, nothing is actually sent: each message is written as an .eml file in {{ bandeja }} so you can still check the flow.

The address people are sent to from every automatic email. It must be the public one, starting with https://.

Many hosting providers block the outbound SMTP ports. Microsoft Graph sends over HTTPS, which is never blocked, and needs no password: it is the option to use with Microsoft 365.

Your Microsoft 365 administrator registers an application in Entra ID, grants it the Mail.Send application permission, and gives you these three values. Nothing else is needed: no password, no open ports, and it is not affected by the retirement of basic authentication.

Automatic emails

Turn any of these off and the platform stops sending it, without touching anything else.

The daily reminder needs the scheduled job on the server to be running. Each person gets a single email listing everything they owe, never one per course, and never twice on the same day.
